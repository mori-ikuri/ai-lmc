# 開発環境と手元にあるもの

2008年4月現在

このファイルに書かれているものが、山田が使えるもののすべてである。
ここに無いものは、社内に存在しないか、山田が使ったことがないものと考える。

## 開発ツール

- Visual Studio 2008 Professional(日本語版)
- Visual Basic .NET
- .NET Framework 3.5
- Windows Forms
- MSDN ライブラリ(DVDでインストール済み)

Service Pack は当てていない。当てるなら自分で判断して入れる。

## データベース

- SQL Server 2005 Express Edition
- サーバ名 `SVR01\SQLEXPRESS`
- SQL Server Management Studio Express

DBは社内サーバに置く。バックアップは毎晩バッチでファイルコピーしている。

## 帳票

Crystal Reports Basic for Visual Studio 2008(10.5)がVSに同梱されており、
インストール済み。備品管理では使っていない。

## クライアント

- Windows XP Professional(SP2 または SP3 が混在)
- 画面解像度は 1024x768 が標準。一部 1280x1024
- Office 2003(Excel 2003)

## ソースコードの管理

共有フォルダ `\\SVR01\share\dev\` に、日付を付けたフォルダごとコピーしている。

```
\\SVR01\share\dev\BihinKanri\
    BihinKanri_20060522\
    BihinKanri_20060830\
    BihinKanri_20071120\
    BihinKanri_20080115\
```

バージョン管理ツールは入っていない。
差分を見たいときは、フォルダを2つ開いて目で比べるか、
テキストの比較ができるフリーソフトを使う。

## ビルドと配置

Visual Studio上でF5で動かして確認する。
配置は、ビルドしたexeとdllを共有フォルダに置いて、
各PCのショートカットから起動させる形にしている。

インストーラは作っていない。

## 使えるライブラリ

.NET Framework 3.5 に入っているものだけ。

外部のライブラリを入れる仕組みは無い。
どうしても必要なら、雑誌の付録CDや窓の杜から落としてきて、
dllを手でコピーして参照設定を追加する。ただし前例はほとんど無い。

## 調べもの

社内からインターネットは使える。

普段見ているもの:

- MSDN ライブラリ(ローカル / オンライン)
- Visual Studio のヘルプ
- @IT、CodeZine などの記事
- Googleで検索して出てくる個人の技術ブログ
- 書店で買ったVB.NETの入門書

英語のページは読むのに時間がかかるので、日本語の情報を優先して探す。

## テスト

自動テストの仕組みは無い。

テスト用のデータベースを別に用意してあり、
画面から実際に操作して結果を目で確認している。
確認が終わったら本番のDBに向け直して配置する。

Visual Studioにテストの機能があるらしいのは知っているが、使ったことはない。

## 参考にする自分のコード

`\\SVR01\share\dev\BihinKanri\BihinKanri_20080115\`

2006年に作った備品管理アプリ。以下が入っている。

- `frmBihinKanri.vb`
- `frmBihinKanri.Designer.vb`
- `modCommon.vb`

新しく作るときは、これを開いて同じ書き方で書く。
命名、コメントの入れ方、エラーの出し方、DBの触り方は、これに揃える。

ソースファイルの文字コードはShift-JIS、改行はCRLF。
