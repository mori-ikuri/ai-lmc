# 2014年2月現在

## タイの締めのその後

去年の夏にタイの締めを作った。

田島さんが月初に、日本の締めと一緒にタイも締めている。
月ごとの合計が固まるようになって、社長への報告で数字が動くことはなくなった。

締めた月の納品は入力も取消もできない。
橋本さんが間違えたときは、田島さんが締めを取り消してから直している。

半年動いているが、苦情は出ていない。

## 数字が変わる件のその後

締めてしまえば動かないので、田島さんはもう気にしていない。

## 日本のほう

国内の請求と入金は6年目。毎月動いている。

得意先は増えたり減ったりしているが、締め日と支払条件の種類は2008年のときから変わっていない。

## 消費税の話

2月に田島さんに呼ばれた。

会計事務所から案内が来たとのこと。

> 「4月から8%になるんですって」

> 「うちのシステム、大丈夫なのかしら」

5%になったのが1997年なので、17年ぶりの変更になる。
山田がこの会社に入る前の話で、そのときのことは誰も覚えていない。

## パソコンの話

Windows XP のサポートが 2014/04/09 で終わる。

総務から回覧が来て、経理と営業のパソコンの台数を2月末までに報告することになった。

入れ替えるかどうかはまだ決まっていない。
販売システムが動かなくなると困る、という話は総務課長にもしてある。

VS2008 も SQL Server 2005 も、今のところ動いている。
